💻 Usage Examples

Initialize Effects

const effects = new NeonEffects(); effects.startLightningStorm(3000); effects.startParticleEffect(300);

Add Neon Glow to Text

effects.addNeonGlow(element, '#00d4ff');

Create Lightning Burst

effects.createLightningBurst( window.innerWidth / 2, window.innerHeight / 2, 8 );

Display Neon Notification

createNeonNotification('Success!', 'success');

🚀 Quick Start

  1. The error pages are automatically integrated with Flask
  2. 404 errors will show the neon error page
  3. 500 errors will show the critical failure page
  4. Visit /loading to see the loading screen
  5. Use the JavaScript API for custom effects
  6. Apply different themes with neonTheme.applyTheme()

⚡ Customization Tips

  • Change colors in CSS variables (--neon-primary, etc.)
  • Adjust animation speeds in @keyframes rules
  • Modify lightning frequency in JavaScript
  • Use multiple themes for different sections
  • Combine effects for dramatic impact
  • Test on mobile devices for responsiveness
