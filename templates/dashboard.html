Operating mode

Monitoring-only mode is configured on the Raspberry Pi with BASELINE_MODE. Relay requests are enforced by the device agent.

Support

Operating notes

  1. Confirm the sensor diagnostics report current readings.
  2. Set instantaneous limits in kW for each channel.
  3. Use the channel switches to request power. The Pi rejects ON requests on sensor or configuration failure.
  4. Verify relay polarity and wiring on a disconnected test load before connecting appliances.
